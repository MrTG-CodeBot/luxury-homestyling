# Luxury Homestyling — Kerala's Premier Interior Styling

Kerala's premier destination for custom motorized curtains, designer blinds, bespoke hand-tufted carpets, and European luxury wallpapers with full doorstep consultation across all 14 districts.

## Tech Stack
- **Frontend**: React, React Router, Vite, Vanilla CSS Design System
- **Backend API**: Node.js, Express, Multer
- **Media & CDN**: ImageKit.io Real-Time Optimization
- **Database & Auth**: Firebase Firestore & Firebase Admin SDK
- **Deployment**: Vercel Ready

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Local Development
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
